# Python 文件自动分类整理工具
一款桌面自动化脚本，根据文件后缀自动归类文件，支持命令行传参，可打包为独立EXE，无需Python环境即可运行。

## 项目功能
1. 根据文件后缀自动分类：图片、视频、文档、音频、压缩包、程序、其他文件
2. 自动创建分类子文件夹
3. 自动检测重复文件，跳过防止覆盖丢失
4. 捕获异常（权限不足、文件占用等），程序不会崩溃
5. 完整日志记录，记录所有移动、创建、报错信息
6. 支持命令行传入目标文件夹，无需修改源代码

## 技术栈
Python、os、shutil、argparse、文件IO、异常捕获、PyInstaller打包
